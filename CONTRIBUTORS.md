## Recognizing contributions

Code, documentation, design, accessibility improvements, testing, bug reports, and thoughtful reviews all help the project.

The [GitHub contributors page](https://github.com/QuinntyneBrown/quinntyne-brown-studio/graphs/contributors) and repository history record merged code contributions. To view commit authors locally, run:

```shell
git shortlog -sn HEAD
```

Issues and pull requests also record non-code contributions. If you would like an acknowledgment added here, include your preferred display name, optional public profile link, and a link to the contribution in a pull request. Only add someone else's name or identifying details with their consent.

Read [CONTRIBUTING.md](CONTRIBUTING.md) to get involved. Third-party software and sample-photo credits are recorded separately in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
