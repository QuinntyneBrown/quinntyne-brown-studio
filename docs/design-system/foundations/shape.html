Foundation

Shape

Five radii and two border widths.

WCAG 2.2 AAStatus: stable
  • Overview
  • Radius scale
  • Which radius
  • Border widths
  • Usage
  • Tokens

Overview

Square, quiet corners. Buttons and inputs use 2px, panels and badges 4px; only tabs and avatars are fully round. The mocks had five radii (2, 3, 4, 30px, 50%); 3px merges into 4px.

Radius scale

--radius-xs
--radius-sm
--radius-md
--radius-lg
--radius-xl
--radius-full

Which radius

ElementToken
Buttons, inputs, alerts, toasts--radius-xs
Panels, badges, chips, dialogs--radius-sm
Menus--radius-md
Tabs, avatars, switches, progress--radius-full

Photographs are never rounded.

Border widths

--border-width-hairline (1px) for every divider and control edge; --border-width-thick (2px) for selected tabs, the focus outline and callouts.

Usage

  • Radius grows with element size only within the scale; do not mix radii inside one component.
  • Nested rounded elements subtract the parent's padding from its radius so corners stay concentric.
