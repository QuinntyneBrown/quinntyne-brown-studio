Iconography

A 24-unit stroke icon set that inherits text colour.

WCAG 2.2 AAStatus: stable
  • Overview
  • Icon set
  • Sizes
  • Labelling rules
  • Code
  • Usage
  • Accessibility

Overview

Icons are inline SVG on a 24-unit grid with a 1.75 stroke, round caps and joins, currentColor. The mocks used typographic glyphs (×, →, +) as icons; they are replaced by this set so they scale and take the label colour.

Sizes

16px inside badges and dense rows, 1.25em (default) beside text, 28px in empty states.

Labelling rules

  • Decorative icon beside a text label: aria-hidden="true".
  • Icon-only control: the control has aria-label; the SVG stays hidden.
  • Icon that carries meaning alone (status): give the SVG role="img" and aria-label, or add visible text.
  • One icon, one meaning across the product.

Code

<svg class="icon" aria-hidden="true" viewBox="0 0 24 24"><path d="M12 5v14M5 12h14"/></svg>

Usage

  • Use .icon; it sets size, stroke and colour inheritance.
  • Do not use emoji or Unicode symbols as icons.
  • Add new icons to this sheet before using them in a page.

Accessibility

  • Icons that convey information pass the 3:1 non-text contrast minimum (1.4.11).
  • Never rely on an icon alone to convey status; pair with text.
