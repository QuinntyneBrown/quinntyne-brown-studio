Layout

Breakpoints, a 4/8/12 column grid, shell dimensions and page templates.

WCAG 2.2 AAStatus: stable
  • Overview
  • Breakpoints
  • Columns, gutters and margins
  • Shell dimensions
  • Page templates
  • Usage
  • Tokens

Overview

Mobile-first. Content sits in a container capped at --layout-container-max; columns, gutters and margins grow at the tablet and laptop breakpoints. The browser acceptance suite checks 390, 768 and 1440 px.

Breakpoints

TokenWidthWhat changes
--layout-breakpoint-sm480pxFour-up grids become two-up; single-column forms stay single.
--layout-breakpoint-md768pxPublic nav collapses below it (menu button); admin sidebar stacks; 8 columns; two-column forms.
--layout-breakpoint-lg1100px12 columns; split layouts (form + summary) go side by side; four-up grids.
--layout-breakpoint-xl1280pxFull admin workspace at standard density.
--layout-breakpoint-2xl1500pxHero image grows; container padding widens.

Drift fixed: the mocks used six unrelated breakpoints (480, 600, 780, 900, 1100, 1500). 600 and 780 merge into 768 and 900 into 1100.

Shell dimensions

  • Container: --layout-container-max (1360px) with --layout-margin side padding.
  • Public header: --layout-header-height (104px). Admin and client top bar: --layout-topbar-height (72px).
  • Admin sidebar: --layout-sidebar-width (220px), sticky, scrolls independently.
  • Reading measure: --layout-measure (65ch).

Page templates

TemplateStructureUsed by
Public pageTop bar, container, footerMarketing home, services, prints, blog, about, contact
WorkspaceSidebar + app bar + main (max 1440px)Every admin and signed-in client screen
SplitMain column + sticky summary (.split)Quote calculator, print request
AuthTwo columns: photograph + form (single column on mobile)Login, forgot and reset password
Centered messageOne narrow column (error page)404, access denied, service error, session expired

Usage

  • Use the layout primitives (.container, .grid, .stack, .split) rather than hand-rolled grids.
  • Media queries use the breakpoint values above in rem.
  • No horizontal page scroll at 320px; only tables and the schedule calendar scroll inside their own wrapper.
