Foundation

Motion

Five durations, four easings, reduced-motion by default.

WCAG 2.2 AAStatus: stable
  • Overview
  • Durations and easings
  • Choreography
  • Reduced motion
  • Usage
  • Accessibility
  • Tokens

Overview

Motion is functional and short. The mocks animate three things: colour changes, an image zoom on photo hover (0.5s) and a skeleton shimmer (1.8s). Everything else is instant.

Durations and easings

Press a button to replay it. Durations are zeroed under reduced motion.

Choreography

  • fast (120ms) hover and colour; base (200ms) reveal, menu, tooltip; slow (320ms) dialog and drawer; deliberate (500ms) image zoom; loop (1.8s) skeleton shimmer.
  • Enter with --ease-enter, leave with --ease-exit, move with --ease-standard. --ease-spring is reserved for the selection tick.
  • Animate transform and opacity, never layout properties.

Reduced motion

Under prefers-reduced-motion: reduce the token layer sets every duration to 0.01ms, so components need no extra media queries. The skeleton shimmer is removed explicitly. The spinner keeps turning because it is a status indicator.

Usage

  • Never auto-play motion for more than five seconds without a pause control (2.2.2).
  • Toasts last at least 8 seconds and pause on hover and focus; errors persist.
  • No parallax and no scroll-jacking.

Accessibility

  • All animation respects reduced motion (2.3.3).
  • Nothing flashes more than three times per second (2.3.1).
