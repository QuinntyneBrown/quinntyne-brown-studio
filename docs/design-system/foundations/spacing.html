Spacing

A 4px scale from 0 to 96px with rules for inside and between.

Overview

A 4px base scale. The mocks used 57 distinct spacing values (many off-grid: 5, 7, 9, 13, 14, 15, 18, 19, 22, 25, 35px); every one snaps to the nearest step below.

Inside and between

  • Inside a component use --space-1 to --space-6: icon gap 8, control padding 12 x 20, panel padding 24.
  • Between components use --space-6 and up: stack gap 20, form sections 32, page sections 80 (--space-20).
  • Page margins come from --layout-margin, not a space step, so they grow with the viewport.
  • Related things sit closer than unrelated things: label to control 8px, field to field 20px, section to section 32px.

Usage

  • Never write a pixel value for spacing in a component stylesheet; use a token.
  • Use gap on flex and grid parents instead of margins on children.
  • A one-off value is a missing step in the scale or a layout bug.

Accessibility

  • Target spacing: adjacent small targets keep at least 8px apart so the 24px minimum target size is met (2.5.8).
  • Spacing in rem scales with text size, so content never collides at 200% zoom.
