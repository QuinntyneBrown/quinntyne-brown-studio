Color

Warm neutrals, a muted olive and three status hues, remapped per theme so components never change.

Overview

Colour is built from a warm neutral ("stone") and a muted green ("olive") taken from the mocks, plus three status hues used sparingly. Ink on white carries the brand; olive marks selection, focus and progress. The primary button is ink, not green.

Components never read the palette. They read semantic tokens (--color-*) that each theme remaps, so dark mode is a token swap with no component CSS.

Usage

  • Status is never colour alone. Pair it with an icon or text: a danger badge says "Failed", an alert starts with a label.
  • One ink button per view. Olive (--color-brand) marks selected photos, progress and the focus ring, never a call to action.
  • Photographs are the colour. Surfaces stay quiet so images carry the page; avoid tinted panels behind photos.
  • Add a brand theme (a second studio) by adding a [data-theme="name"] block that overrides semantic tokens only, then extending contrast-pairs.json and re-running the checker.

Accessibility

Both themes pass WCAG 2.2 AA for every declared pair. prefers-contrast: more promotes borders and muted text to the strong tokens; forced-colors: active hands the focus ring and borders to system colours.
