Selection bar

The selection bar sits above a photo grid or table and shows how many items are selected, with the actions that apply to the selection.

WCAG 2.2 AAStatus: stableStatus region

Overview

Use a selection bar wherever people choose several items and then act on them: a client picks photographs for prints, an admin approves a batch. It pairs with photo tiles and a selectable table. For actions on one item use a menu or a row button.

  • The count comes first, as plain text, and announces itself politely when it changes.
  • Quiet actions (Select all, Clear) are ghost buttons; the main action is the single primary button.
  • The bar sits in flow above the content; it does not float over it.

Anatomy

  1. CountA bold number and a noun, in a polite status region.
  2. Quiet actionsSelect all and Clear: ghost small buttons.
  3. Primary actionOne primary button for the main outcome; secondary actions are default buttons.

Variants

The bar always has the same three parts; only the actions change with the context.

HTML
<div class="selection-bar" role="region" aria-label="Photo selection">
  <span role="status" aria-live="polite"><strong>12</strong> photographs selected</span>
  <div class="cluster">
    <button class="btn btn--ghost btn--sm" type="button">Select all</button>
    <button class="btn btn--ghost btn--sm" type="button">Clear</button>

Sizes

The bar has one size; the buttons inside it are small.

The bar reflects the selection. Pointer and focus states of the buttons come from button.

Both themes

12 photographs selected
12 photographs selected
  • Nothing selected: keep the bar visible with actions disabled when the screen is about selecting; hide it when selecting is an occasional action. Disabled buttons need the reason in the count text.
  • Working: the pressed action shows its loading state; the other actions stay enabled unless they conflict.
  • Result: confirm with a toast or an inline message and clear the selection.
  • Plural: "1 photograph selected", not "1 photograph(s)".

Responsive behaviour

  • The bar is flex-wrap: the count and buttons share one row when they fit and the buttons wrap beneath at narrow widths.
  • Below 480px reduce the actions: keep the primary and Clear; move the rest into a menu.
  • When the list is long, the bar may become sticky at the top of the scroll area; ensure it never covers the focused item (WCAG 2.4.11).

Theming

Background --color-bg-subtle, count in default ink. Buttons carry their own theme. In dark mode the bar's fill darkens with the page; the count keeps 4.5:1.

Accessibility

Role and pattern

A labelled role="region" (or a plain <div> when the page already has landmarks nearby) containing a polite role="status" count and native buttons. No custom widget role.

Keyboard

KeyAction
Tab / Shift+TabMoves through the buttons in DOM order.
Enter, SpaceActivates a button.
EscClears the selection when the bar has focus (optional shortcut).
Ctrl/Cmd+AOptional: selects all items when focus is in the grid.

Focus

Each button shows the shared ring. When Clear empties the selection and the bar hides, focus moves to the first item in the grid. After an action completes, return focus to the primary button, or to the first remaining item.

Labelling

The region is named for what is selected ("Photo selection"). The count region is announced on change: "12 photographs selected". Buttons say what they do to the selection ("Request prints"), not "Go".

Motion

The bar appears without animation. If it slides in, honour reduced motion by cutting the duration to zero.

Touch

Small buttons are 32px with 8px between them (meets 24px). On touch screens below 768px switch the bar's buttons to the default 44px size.

Content

  • Counts are numerals with a noun: "12 photographs selected".
  • Actions are verb phrases naming the outcome: "Request prints", "Add to album".
  • Use "Select all" for the loaded page and say "Select all 240" when it extends across pages.
  • Destructive bulk actions repeat the count: "Archive 2 sessions".
  • Do not repeat the count in a toast after the action.
