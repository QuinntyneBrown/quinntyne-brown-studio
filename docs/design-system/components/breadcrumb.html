Breadcrumb

A breadcrumb shows where this page sits in the hierarchy and gives a one-click way back up.

WCAG 2.2 AAStatus: stableAPG Breadcrumb

Overview

Use a breadcrumb on pages that are two or more levels deep: a photo inside an album inside a session, or an editor inside a catalogue. It complements the top bar and sidebar; it does not replace them. Do not use it on top-level pages, and do not use it to show the path the person happened to take.

  • Full: every ancestor is a link and the last item is the current page.
  • Collapsed: on long trails the middle levels collapse behind an ellipsis button that reveals them in a menu.
  • Back link: for one-step editors the mocks use a single "← Back to ..." link, which is the right answer when there is only one level up.

Anatomy

  1. LinkAn ancestor page. Ink text, underlined on hover by the default link style.
  2. SeparatorA / drawn by CSS li + li::before, so it is never read by screen readers.
  3. Current pageThe last item, muted, with aria-current="page"; it may be a link or plain text.

Variants

Breadcrumbs share one markup; collapse the middle when the trail is long.

Full

  1. Your sessions
  2. Wedding session
  3. Ceremony
Three levels: the client's sessions, one session, one gallery.
HTML
<nav class="breadcrumb" aria-label="Breadcrumb">
  <ol>
    <li><a href="/client/galleries">Your sessions</a></li>
    <li><a href="/client/gallery">Wedding session</a></li>
    <li><a href="/client/photo" aria-current="page">Ceremony</a></li>
  </ol>
</nav>

Collapsed

  1. Sessions
  3. Photo review
  4. Ceremony
Keep the first level, the last two, and an ellipsis button for the rest. The button opens a menu of the hidden ancestors.

Back link

← Back to sessions
When there is a single level up, a back link is shorter than a breadcrumb and reads clearly.

Sizes

The breadcrumb has one size: caption text (12px) in a single line that wraps.

States

Only links have states. The current item is not interactive on its own page. Hover on links changes only through :hover; focus and current are shown.

  • Current page is muted text with aria-current="page". Make it a link to the same page, or plain text; both are valid.

Responsive behaviour

  • The list wraps; each item stays on one line.
  • At 390px show the full trail if it fits on two lines, otherwise collapse to first, ellipsis and parent only.
  • On phones the parent link alone (the back link variant) is often better than a trail.
  • The trail sits above the page title, outside the shell's content padding of the heading, so it lines up with the title's left edge.

Theming

The breadcrumb uses --color-fg-default for links and --color-fg-muted for the current item and separators. Both flip in the dark theme with no component tokens.

Accessibility

Role and pattern

WAI-ARIA APG Breadcrumb: a <nav aria-label="Breadcrumb"> landmark wrapping an ordered list (<ol>); the current page has aria-current="page".

Keyboard

KeyAction
Tab / Shift+TabMoves through the ancestor links in order.
EnterFollows the focused link.
Enter, SpaceOn the collapsed ellipsis button: opens the menu of hidden levels.

Focus

Links show the shared focus ring (2px --color-focus-ring, 2px offset). The ellipsis button also takes the ring; opening its menu moves focus into the menu and Esc returns it.

Labelling

The landmark is named "Breadcrumb" so it is distinguishable from the main navigation. The ordered list tells assistive tech the number of levels. The ellipsis button's name states what it hides ("Show 2 hidden levels").

Contrast

Link on page
Current item on page
Focus ring on page

Motion

No motion.

Touch

Items are text links at 12px with 8px gaps; the target is only the text height, which just meets the 24px minimum when the line height is applied. In touch-first views prefer the back link (44px high) over the trail.

Content

  • Use the page's real title for each level, not a generic label: "Wedding session", not "Session".
  • Sentence case, no trailing punctuation.
  • The last item repeats the page's heading, shortened if it is long.
  • Do not put "Home" first on a client or admin trail; the brand already goes home.
  • Back links say where they go: "Back to sessions", not "Back".
