Stat

A stat puts one number in front of people with a label and a line of context: sessions this month, photos awaiting review, quotes sent.

WCAG 2.2 AAStatus: stableStatic region

Overview

Use a stat for the few numbers that frame a dashboard or a report. Use a table for many numbers and a badge for a status word. Show at most four stats in a row; more than that stops being a summary.

  • Plain: label, number, context line.
  • With change: the context line carries a badge such as "+4 vs September"; the sign and word, not colour, carry the direction.
  • Loading, zero and error keep the card's shape so the page does not jump.

Anatomy

  1. LabelOverline text naming what is counted. Reads first, so the number is understood in context.
  2. NumberSerif, 2xl, tabular figures. One value only.
  3. Context lineCaption in muted ink: a period, a comparison or what needs attention.

Variants

Stats sit in a grid of up to four columns. They have no links or actions of their own; to drill in, put a link in the context line.

  • Zero shows "0", not blank, with a context line that explains the absence.
  • Loading uses skeleton blocks of the same height and aria-busy="true". The shimmer stops under reduced motion.
  • Error shows an em dash and a Retry link; do not show a stale number as if it were current.
  • Updates: when the number changes live (a quote total), put it in a region with aria-live="polite".

Responsive behaviour

  • Stats are laid out by the grid: four columns from 1100px, two from 480px, one below. The number does not shrink.
  • On a phone the order of stats is the order of importance, because they stack.
  • The label may wrap to two lines; the number never wraps.

Theming

Border from --color-border-default, label and context from --color-fg-muted, number from --color-fg-default in the serif family. Nothing needs overriding in dark mode.

Accessibility

Role and pattern

Static content in an <article> or <div>. The label precedes the number in the DOM so a screen reader hears "Sessions this month, 12, 3 awaiting review". No ARIA role is needed; a grid of stats may be wrapped in a list if the count matters.

Keyboard

KeyAction
TabReaches only a link or button inside the context line.
EnterFollows a link in the context line.
EscNo effect.

Focus

The stat takes no focus. A link or button inside shows the shared ring.

Labelling

The label and number are read in order; do not hide the label. If the number alone appears in a heading, add the label with aria-describedby. Compare-to values must include the sign and the unit in text.

Motion

No count-up animation. The number appears at its value.

Touch

A stat is not a target. A link in the context line is at least 24px high; give it padding where stats are closely packed.

Content

  • Labels are nouns for what is counted with a period: "Sessions this month".
  • Numbers use thousands separators and the currency symbol: "$8,400".
  • Context lines are one short sentence fragment; no period.
  • Comparisons name the baseline: "+4 vs September", not "+4".
  • Do not abbreviate to "8.4k" unless space truly forbids it.
