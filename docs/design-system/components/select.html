Select

A select lets a person choose one option from a list of about five to fifteen, using the browser’s own picker.

WCAG 2.2 AAStatus: stableNative <select>

Overview

Use a select for one answer from a longer list: a session type, a print size, a province. For two to four options show a radio group so the choices are visible; for many options plus search consider a combobox, which this system does not yet ship. Wrap the select in a form field.

  • Native is the default. It gives mobile pickers, type-ahead and screen reader support for free.
  • With placeholder starts on a disabled, hidden-value option such as "Choose a session type".
  • Filter selects in a toolbar use the small size and a visible or aria-label label.

Anatomy

  1. LabelVisible, above the control, tied with for.
  2. Selected valueShows the chosen option in the same type as a text field.
  3. ArrowDrawn by the browser; it indicates the control opens a list.

Variants

Native selects only. The list itself is drawn by the operating system, so it is not themed beyond color-scheme.

Default

The first option is selected unless a placeholder is used.
HTML
<label class="field__label" for="type">Session type</label>
<select class="input" id="type">
  <option>Wedding</option>
  <option>Family portrait</option>
</select>

With placeholder

The placeholder option is disabled so it cannot be re-selected.

Option groups

Use optgroup when the list has natural categories.

Toolbar filter

A visually quiet filter. The label is carried by aria-label because the toolbar already shows its purpose.

Sizes

Same three heights as the text field. Small is for filter rows; large is for the quote calculator.

Heights: --control-height-sm/md/lg.

States

Closed-state appearance is documented; the open list is drawn by the browser. Hover and focus are forced with data-state for review.

Both themes

  • Open is the operating system’s list; its colours come from color-scheme, which the theme sets.
  • Invalid is paired with a visible message in the form field ("Choose a print size").
  • Disabled options inside a list use the native attribute and are skipped by the keyboard.

Responsive behaviour

  • Full width of the column on phones, where the native picker takes over the screen. In toolbars the select keeps its natural width.
  • Long option labels wrap in the picker; keep them short enough to read in the closed control at 390px.
  • Never replace the native select with a custom list on small screens; it loses the platform picker.

Theming

A select reads the same tokens as the text field. The dropdown arrow and the open list follow the page color-scheme, so they switch with the theme without extra CSS.

Accessibility

Role and pattern

Native <select> (WAI-ARIA APG Combobox, select-only variant, provided by the browser). A custom listbox is only added when the native control cannot do the job, and then follows APG Listbox.

Keyboard

KeyAction
Tab / Shift+TabMoves focus into and out of the select.
↓ ↑Changes the value in a closed select, or moves in the open list.
Alt+↓, Space, EnterOpens the list (browser dependent).
Letter keysType-ahead jumps to the next option that starts with that text.
Home / EndFirst or last option.
EscCloses the open list without changing the value.

Focus

The shared ring and a focus-colour border on :focus-visible. When the list closes, focus stays on the select.

Labelling

A visible <label for>; aria-label only for toolbar filters. A placeholder option is disabled and has an empty value so "nothing chosen" can be validated. Required selects set required and say so in the label.

Contrast

Text on field
Border on surface
Invalid border on surface
Focus ring on surface

Motion

No custom animation; the browser opens the list.

Touch

44px high at medium and large; small (32px) only in toolbars. On phones the native picker gives each option a large target.

Content

  • Label is the thing being chosen: "Session type", "Print size".
  • Placeholder option starts with a verb: "Choose a print size".
  • Order options by how people think (size ascending, popularity) and not alphabetically unless it is a lookup list.
  • Sentence case. Include units in each option ("8 x 10 in").
