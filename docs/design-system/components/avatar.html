Avatar

An avatar is a small round mark that stands for a person: a photographer, a client, the signed-in user. It shows initials, or an icon when there is no name.

WCAG 2.2 AAStatus: stableDecorative or labelled

Overview

Use an avatar beside a name to make people easier to scan in lists, schedules and the account menu. Use a badge for status and a card for a full profile.

  • Initials are the default: one or two letters taken from the name.
  • Icon stands in when the name is unknown, such as a walk-in inquiry.
  • Group overlaps nothing: avatars sit in a row with an overflow count when there are more than four.

Anatomy

  1. DiscCircular container, --radius-full, filled with --color-brand-subtle.
  2. Initials or iconCaption-size type in default ink; an icon is aria-hidden. The name next to it is the accessible name.

Variants

Initials are the studio default. The adjacent name carries the meaning, so the avatar is hidden from assistive technology unless it stands alone.

Sizes

Three sizes: small for dense rows, medium for lists and menus, large for profile headers.

QBQBQB
1.5rem (24px), 2rem (32px) and 3rem (48px).

States

An avatar has no interaction state. When it is the content of a button, the button's states apply. The matrix shows the avatar inside a ghost icon button.

Both themes

QBMCNW
QBMCNW
  • Image failed or missing: fall back to initials, then to the icon. Never show a broken image.
  • Loading: use .skeleton.skeleton--circle from skeleton.
  • Status dot is not part of this component; pair the name with a badge instead.

Responsive behaviour

  • The avatar never changes size with the viewport; size is chosen by context.
  • In the app top bar the name beside the avatar collapses first; the avatar stays so the account menu keeps a recognisable trigger at 390px.
  • Groups wrap onto a second row rather than overlapping or clipping.

Theming

The disc uses --color-brand-subtle with default ink. In the dark theme the fill darkens and the ink lightens together, so initials stay above 4.5:1. A product can recolour the fill by overriding --color-brand-subtle on a wrapper.

Accessibility

Role and pattern

Presentational. When next to a visible name the avatar is aria-hidden="true". When it is the only content, it sits inside a control or has role="img" with an aria-label that names the person. See the APG names and descriptions guidance.

Keyboard

KeyAction
TabAn avatar is not focusable. If wrapped in a button, the button takes focus.
Enter, SpaceActivate the wrapping button.
EscCloses a menu opened from an avatar button.

Focus

The avatar never takes focus. A wrapping button shows the shared 2px ring around the button, not the disc.

Labelling

Hidden next to a name. Alone: label the control, not the disc ("Account menu for Quinntyne Brown"). For groups label the container with the full list of people.

Contrast

Initials on avatar
Muted caption on surface

Motion

No motion.

Touch

The disc alone is 24 to 48px and not a target. An avatar button uses the 44px icon button, which exceeds the comfortable target.

Content

  • Initials are the first letter of the first and last name in capitals: Quinntyne Brown becomes QB.
  • Use one letter for single names.
  • Never put a person's photo in the disc without alt or a visible name.
  • Overflow counts read "+2", with the full list in the group label.
