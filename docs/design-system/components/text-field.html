Text field

A text field takes a single line of text: a name, an email address, a password, a price or a search term.

WCAG 2.2 AAStatus: stableNative <input>

Overview

Use a text field for short, single-line answers. Use a textarea for more than a sentence, a select or radio group for a fixed set of answers, and the native date input for dates. Always place it inside a form field so it has a label, a hint and an error.

  • Set the right type and autocomplete: the keyboard, validation and autofill all follow from it.
  • Search fields sit in a toolbar and pair with a button.
  • Prefix and suffix add units or actions with .input-group.

Anatomy

  1. LabelAbove the control, linked with for and id.
  2. Prefix or suffix (optional)A unit or action next to the input; decorative text is aria-hidden and repeated in the label.
  3. Input44px high, 1px --color-border-strong border, --radius-xs, text at --font-size-sm.

Variants

Types differ by keyboard and validation, not by looks. Every type shares the same border, height and states.

Common types

Text, email and telephone. Placeholders show format only; the label still names the field.
HTML
<label class="field__label" for="email">Email</label>
<input class="input" id="email" type="email" autocomplete="email">

Password with show toggle

The toggle is a labelled button with aria-pressed; it never moves focus.

Search

Search fields use role="search" on the form and a button, since a magnifier icon alone does not label itself.

Prefix and suffix

hours
The unit follows the value and is tied by aria-describedby.

Sizes

Medium (44px) is the default. Small is for toolbars and filter rows; large is for the quote calculator and auth screens where the field is the focus.

Heights: --control-height-sm/md/lg.

States

Hover and focus are forced with data-state for review. Invalid uses aria-invalid; real pages get the rest from :hover, :focus-visible and :disabled.

Both themes

  • Focus thickens nothing; it changes the border to --color-focus-ring and adds the shared ring so the state does not rely on colour alone.
  • Disabled removes the field from the tab order and its value from the submission. Prefer read-only when the person should still read, select and copy the value.
  • Invalid is paired with a visible error in the form field; the red border alone never carries the message.

Responsive behaviour

  • Fields fill their column. At 390px they are full width; a prefix or suffix keeps its natural width and the input shrinks.
  • Font size is at least 16px on touch devices so iOS does not zoom on focus; the token --font-size-sm is raised to 16px under the coarse-pointer query.
  • Do not set a fixed width on a field: size by content with max-width in a layout, not size.

Theming

Fields read --color-bg-surface for the fill, --color-border-strong for the border and --color-fg-default for text. In the dark theme the fill darkens with the surface and the border lightens so it stays above 3:1. The invalid and focus borders are set through the local --field-border property, which a product can override on the host.

Accessibility

Role and pattern

Native <input> with a <label> (WAI-ARIA APG Textbox: no custom role is added). Search uses role="search" on the surrounding form.

Keyboard

KeyAction
Tab / Shift+TabMoves focus into and out of the field.
Typing, ← → Home EndNative text editing.
EnterSubmits the enclosing form when it has a submit button.
EscClears a type="search" field in browsers that support it.

Focus

The border switches to --color-focus-ring and the shared 2px ring appears on :focus-visible. Text is selected on focus only when the field is a code or token the person is likely to replace.

Labelling

A visible <label for> is required. Use aria-label only for search and toolbar fields where a visible label would repeat the button. Set autocomplete on name, email, phone and address fields (WCAG 1.3.5). Required fields say "required" in the label as well as setting required.

Contrast

Motion

The border colour transitions over --duration-fast. Nothing moves.

Touch

Medium and large fields are 44px or taller. The small field (32px) is used in toolbars and filter rows with 8px between neighbours.

Content

  • Labels are nouns in sentence case; do not end them with a colon.
  • Placeholders show an example format ("name@example.com"), never an instruction or the label.
  • Do not pre-fill with sample data that looks like a real answer.
  • Name units in the visible text: "Coverage (hours)", not a bare number.
