Skeleton

A skeleton is a grey placeholder in the shape of the content that is loading. It keeps the layout from jumping and tells people roughly what is coming.

WCAG 2.2 AAStatus: stableDecorative, aria-hidden

Overview

Use a skeleton for content whose layout is known: a gallery grid, a table, a card, a list of sessions. Use a spinner when the shape is unknown, and progress when the length is known. Skeletons are decorative: the region they sit in announces loading through aria-busy. See feedback and loading.

  • Text and title bars stand in for lines of copy.
  • Circle stands in for an avatar.
  • Block (the base class) stands in for an image such as a photo tile.
  • Composed placeholders combine them to match a card or a row.

Anatomy

  1. Image blockBase .skeleton; set its height to match the real image or use aspect-ratio.
  2. Title bar.skeleton--title, 60% wide and 1.75rem tall.
  3. Text bars.skeleton--text, one per line; vary the last line's width so it reads as copy.

Variants

Match the placeholder to the layout it stands in for: same widths, same gaps, same number of rows. A mismatch makes the real content jump when it arrives.

Text and title

A heading and three lines of copy.
HTML
<div aria-hidden="true">
  <span class="skeleton skeleton--title"></span>
  <span class="skeleton skeleton--text"></span>
  <span class="skeleton skeleton--text" style="width: 70%;"></span>
</div>

Circle

Avatar and two lines, as in a client or photographer row.

Composed card

A gallery card: image, title, two lines.

Loading region

Loading galleries
The container is aria-busy="true" and has one hidden status message; the bars are aria-hidden.

Sizes

Skeletons take the size of the content they stand in for; there are no fixed sizes.

States

A skeleton is either shown or replaced by content. It does not respond to the pointer or keyboard. Its only motion is a slow shimmer.

Both themes

  • Reduced motion: under prefers-reduced-motion: reduce the shimmer stops and the bars become flat tints. The column here marks the state; the real switch is the media query.
  • Loaded: replace the skeleton with the content in the same box, set aria-busy="false", and keep focus where it was.
  • Failed: replace the skeleton with an alert or empty state; never leave it shimmering forever.

Responsive behaviour

  • Skeleton grids use the same columns as the real grid, so photo grids show 2, 3 or 4 columns by breakpoint exactly as the real ones do.
  • Show only as many placeholders as fit on the first screen; do not render 50 bars.
  • Percent widths on text bars scale with the container, so the shape stays proportional at 390px.

Theming

The placeholder is a gradient between --color-bg-subtle and --color-bg-surface-sunken, which are both close to the surface they sit on so the shimmer is quiet. In the dark theme the pair darkens with the surface. Because skeletons are decorative, they are not required to meet text contrast, but they remain visible against the page.

Accessibility

Role and pattern

No APG widget. The loading region uses aria-busy="true"; the placeholder bars are aria-hidden="true". One visually hidden role="status" element announces what is loading.

Keyboard

KeyAction
TabSkeletons are not focusable. Controls that are already usable (such as filters) stay in the tab order while the data loads.

Focus

Do not move focus into a loading region. When content arrives, leave focus where it was; if the focused element was replaced, move focus to the heading of the new content.

Labelling

Mark the container aria-busy="true" and put one hidden status message in it ("Loading galleries"). Mark every bar aria-hidden="true" so screen readers do not read empty elements.

Motion

The shimmer runs once every --duration-loop (1.8s) and stops under prefers-reduced-motion: reduce. It never flashes: the gradient is low contrast and moves slowly.

Touch

Not interactive. No touch target.

Content

  • Skeletons contain no text. The loading message is hidden text for screen readers only.
  • Do not show placeholder copy such as "Lorem ipsum" inside bars.
  • If loading takes more than about 10 seconds, replace the skeleton with progress or a message that says what is happening.
