Date navigator

The date navigator steps through time one period at a time, so a person can move between weeks or months on a schedule without opening a calendar.

WCAG 2.2 AAStatus: stableTwo buttons and a live label

Overview

Use the date navigator above a schedule, agenda or report: "Previous week", "Next week", and the range shown between them. It changes what the page shows, so it is made of buttons, not links. For picking a specific date use a text field with the native date input, or the calendar.

  • Week steps seven days and shows the first day of the week.
  • Month steps a calendar month and shows the month and year.
  • With today adds a "Today" button that returns to the current period.

Anatomy

  1. Previous buttonIcon-only small button; aria-label names the period ("Previous week").
  2. Range labelText of the current period, in a polite live region so the change is announced.
  3. Next buttonSame as previous, pointing forward.

Variants

One structure; the period and the optional Today button change.

Week

Oct 12 – 18, 2026
The default on the schedule screen.
HTML
<div class="date-nav" role="group" aria-label="Week navigation">
  <button class="btn btn--sm btn--icon" type="button" aria-label="Previous week">…</button>
  <strong aria-live="polite">Oct 12 – 18, 2026</strong>
  <button class="btn btn--sm btn--icon" type="button" aria-label="Next week">…</button>
</div>

Month

October 2026
Labels follow the period: month names a month, never a week.

Sizes

The navigator uses small buttons (32px) with a body-small label. It is a toolbar control, not a hero control.

States

The buttons carry the states; the label changes with the period.

  • Loading: while the new period loads, set aria-busy="true" on the content region (not on the buttons) and keep the buttons enabled so the person can keep stepping.
  • Limits: disable "Previous" at the earliest allowed period and say why nearby; do not wrap around.
  • Today disabled means the current period is already showing.

Responsive behaviour

  • The group stays on one row at 390px: the label may shrink to the short form ("Oct 12–18") with the full range as the live text.
  • On wide screens it sits beside the page heading or above the calendar; on narrow screens it takes its own row and centres.
  • The label never wraps onto a second line.

Theming

The navigator adds no colour of its own. The buttons use the secondary button tokens and the label uses --color-fg-default. The range label is the only text, so contrast depends on the surface it sits on.

Accessibility

Role and pattern

A role="group" of two native buttons and a live text label. It is not a tablist or a slider; each press changes the view and the label announces the new period.

Keyboard

KeyAction
Tab / Shift+TabMoves between Previous, Next and Today.
Enter, SpaceSteps the period.
Alt+← / Alt+→Optional shortcut for previous and next; if added, document it in the page and never override browser history keys.

Focus

The shared ring on the focused button. Focus stays on the pressed button while the schedule updates; it is never moved to the new content.

Labelling

The group has an aria-label ("Week navigation"). Buttons are icon-only, so each has an aria-label that names the period and direction. The range text is in aria-live="polite" so the new range is announced once per change.

Motion

The schedule updates without sliding. Any animation between periods must be removed under prefers-reduced-motion.

Touch

Small buttons are 32px square with --space-3 between them: above the 24px minimum. On coarse pointers use medium buttons (44px).

Content

  • The label states the period in plain words: "Oct 12 – 18, 2026", "October 2026".
  • Button names match the period: "Previous week", "Next month".
  • Use an en dash in ranges and abbreviate months only where space demands it.
  • Show "Today" in sentence case; do not use "Now".
