Photo tile

A photo tile is one photograph in a grid: a 4:5 crop with a select checkbox, a position label and an optional status badge.

WCAG 2.2 AAStatus: stableSelectable image

Overview

Use photo tiles to review, choose and order photographs in session galleries, albums and uploads. Use a card for a titled item with text and a blog card for articles. Tiles are laid out by .photo-grid: two columns on a phone, three from 768px.

  • Plain: image and position label.
  • Selectable: a checkbox with a visible "Select" label sits top left; selecting outlines the tile.
  • With badge: a badge top right for AI suggested, approved, unavailable.
  • Fallback: when the file is missing, a quiet text tile keeps the grid intact.

Anatomy

  1. ImageObject-fit cover in a 4:5 frame. Always has alt describing the photograph.
  2. Select controlA real checkbox in a label on a surface-coloured chip so it reads on any photo.
  3. Status badge (optional)A badge in the top-right corner; text carries the status.
  4. Position label"01 / 24" on a surface chip bottom left; helps people refer to a photo by number.

Sizes

Tiles have no size options; the grid sets the column width and the 4:5 ratio sets the height.

States

Hover scales the image 2.5%. Selection adds an outline and a checked box. Focus lands on the checkbox and on the open button.

  • Focus: the checkbox shows the shared 2px ring; when a tile opens a lightbox the open control also does.
  • Selected and disabled: tiles of photos that can no longer be selected (already ordered) disable the checkbox and show an "Ordered" badge.
  • Hover is decorative; the scale stops under reduced motion because transitions are zeroed by the motion tokens.
  • Bulk selection is announced by the selection bar.

Responsive behaviour

  • Two columns below 768px, three from 768px, with the gap rising from --space-3 to --space-5. Tiles keep a 4:5 ratio.
  • At 480px and below the status badge moves from the top right to the bottom left so it does not collide with the select chip; the select chip tightens.
  • A grid of more than about 60 tiles should paginate or lazy-load; see pagination.
  • The select chip is always visible; do not reveal it only on hover, because touch screens have no hover.

Theming

The chips on the photo (select, label, badge) use --color-bg-surface and default ink so they read on any photograph in either theme. The selection outline uses --color-brand. The empty frame uses --color-bg-subtle, the fallback --color-bg-surface-sunken.

Accessibility

Role and pattern

A group of images with native checkboxes. The grid is a list of images, not an ARIA listbox or grid; selection is the checkbox's state. Where a tile opens a larger view, wrap the image in a button that opens a dialog (lightbox).

Keyboard

KeyAction
Tab / Shift+TabMoves checkbox by checkbox (and open buttons) in DOM order.
SpaceToggles the focused checkbox.
EnterActivates the open button, if present.
EscCloses the lightbox and returns focus to the tile that opened it.

Focus

The checkbox is the focus target and shows the shared ring. The selected tile's thick outline is additional, not a replacement for the ring. Lightbox: focus returns to the tile's open button on close.

Labelling

Each image has descriptive alt (what is photographed, not the file name). The checkbox has a visually hidden name: "Select photo 02". The visible "Select" text is aria-hidden to avoid double reading. The badge text is read as part of the tile. Announce the selection count in the selection bar's live region.

Motion

Hover scales the image by 2.5% over --duration-deliberate. Reduced motion zeroes the duration. No other animation.

Touch

The checkbox chip is about 28px tall and 20px for the box. On touch screens make the whole chip the label (it is) and keep 8px between neighbouring tiles; opening the photo is the large target.

Content

  • Alt text describes the photograph in one sentence: "Couple walking through a garden". Never the file name or "photo".
  • Position labels read "01 / 24", zero-padded to the grid size.
  • Badges say a status word: "Approved", "AI suggested", "Unavailable".
  • Fallback text: "Preview unavailable"; do not blame the person.
  • Checkbox accessible names say "Select photo 02", not "Checkbox".
