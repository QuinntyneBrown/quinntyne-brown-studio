Link

A link takes the person somewhere else: another page, a section, a file or another site. It is underlined so it can be found without relying on colour.

WCAG 2.2 AAStatus: stableNative <a href>

Overview

Use a link when activating it navigates. Use a button when it changes something. A link that looks like a button is still a link: give it the href and style it with the button classes. A button that looks like a link is a .btn--link.

  • Standalone is the default: a hairline underline, used for calls to action such as "View all sessions" and for footer and card links.
  • Inline sits inside a sentence and is underlined with a text decoration so it flows with the copy.
  • External opens a different site. It adds an arrow and a visually hidden "opens in a new tab" note.

Anatomy

  1. LabelDescriptive text that makes sense out of context; it is the accessible name.
  2. UnderlineA hairline border (standalone) or text decoration (inline). Never colour alone.
  3. External markerAn arrow added with ::after, paired with hidden text for screen readers.

Variants

Pick by context: standalone for calls to action, inline for body copy, external for any destination outside the studio site.

Sizes

A link takes the font size of the text around it, so it has no size scale of its own.

States

Links respond to hover, focus and keyboard activation. Hover and focus are forced with data-state for review; real pages use :hover and :focus-visible.

Both themes

StandaloneInlineExternal
  • Visited is not restyled: the studio sites are task-driven and a changing colour adds noise. The link colour already passes in both themes.
  • Disabled does not exist. A link that cannot be followed is removed or replaced with plain text and a reason.
  • Current page is marked with aria-current="page" in navigation; see top bar.

Responsive behaviour

  • Links wrap with the text around them. Standalone links break the underline cleanly across lines because it is a border on the inline box.
  • Link text never truncates. A target that is narrow on a phone gets vertical room from its row, not from the link itself.
  • In a stacked list of links (footer, card actions) give each row at least 44px of height so it is an easy target at 390px.

Theming

Links read --color-fg-link and --color-fg-link-hover. The brand is ink and olive, so the link colour is the ink foreground and the underline carries the affordance; both tokens change per theme and keep 4.5:1 on the canvas and on cards. Re-skin by redefining the two tokens.

Accessibility

Role and pattern

Native <a href> (WAI-ARIA APG Link). Never a <span> or <div> with a click handler, and never <a> without an href.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the link.
EnterFollows the link. Space scrolls the page, as for any link.
Ctrl/Cmd+EnterOpens in a new tab (browser behaviour; do not intercept).

Focus

The shared ring (2px --color-focus-ring, 2px offset) shows on :focus-visible. It surrounds the whole link box, including the external arrow.

Labelling

The link text is its name and must make sense alone: "Read the print terms", not "Click here" or "More". External links include visually hidden "(opens in a new tab)" text. Use rel="noopener" with target="_blank".

Motion

Only the colour changes on hover, instantly or over --duration-fast. No movement, so nothing to reduce.

Touch

A standalone link in running text can fall below 24px tall, which WCAG 2.2 allows for inline targets. Links in lists, cards and footers sit in rows of at least 44px.

Content

  • Describe the destination: "View session details", "Download the price list".
  • Never "click here", "read more" or a bare URL as the label.
  • Keep a link to the length of its meaning, three to six words, and leave the full stop outside the underline.
  • Name file links with the type and size when useful: "Price list (PDF, 240 KB)".
