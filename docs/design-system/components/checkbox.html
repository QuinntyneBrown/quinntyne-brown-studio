Checkbox

A checkbox records a yes-or-no choice, or lets a person pick any number of options from a short list.

WCAG 2.2 AAStatus: stableNative <input type="checkbox">

Overview

Use a checkbox for an independent yes/no, such as "Email me the gallery link", or for choosing several items from a list, such as the photos in a print request. Use a radio group when exactly one answer is allowed, and a switch for a setting that takes effect immediately. Checkbox groups sit in a fieldset with a legend.

  • Single for consent and options.
  • Group for several related options under one legend.
  • With description adds a muted second line for the consequence.
  • Card frames a choice that needs more room, such as an add-on with a price.

Anatomy

  1. BoxNative checkbox, 1.25rem square, filled with --color-accent when checked.
  2. LabelWraps the input so the whole row is the target, at least 44px tall.
  3. Description (optional)Caption in muted foreground, inside the same label so it is read with the name.

Variants

All variants are the native input; the wrapper decides layout.

Single with description

The description lives inside the label so it is announced with it.
HTML
<label class="check">
  <input type="checkbox" checked>
  <span>Email me the gallery link<small>Sent when the photographer publishes.</small></span>
</label>

Group

Deliverables
A fieldset and legend name the group; each checkbox is its own tab stop.
HTML
<fieldset class="fieldset">
  <legend>Deliverables</legend>
  <label class="check"><input type="checkbox" checked>Online gallery</label>
  <label class="check"><input type="checkbox">Printed album</label>
</fieldset>

Card style

Use cards when each option has a price or consequence.

Sizes

The box is a fixed 1.25rem (20px) and the row is at least 44px tall. There is no size scale; scale the label text through the surrounding type.

States

The native control has the full set of states. Indeterminate is a property set by script (input.indeterminate = true), so it is described below instead of drawn statically.

Both themes

  • Indeterminate shows a dash for a parent checkbox when only some children are checked ("Select all photos"). Set it with script and sync it with the children; clicking a parent makes all children match it.
  • Invalid applies when a required box is unchecked on submit ("Accept the print terms"); the message goes in the surrounding form field or error summary.
  • Disabled boxes are dimmed and skipped; explain why in the description.

Responsive behaviour

  • Checkbox rows stack in one column at every width; two columns are allowed only when every label is a single short word.
  • Cards fill the column. Descriptions wrap beneath the label.
  • The label is part of the target, so there is no need to enlarge the box on touch.

Theming

The box uses the browser’s native control with accent-color: var(--color-accent), so the checked fill and tick pair follows the theme: ink with a white tick in light, near-white with a dark tick in dark. Card style uses --color-brand for the selected border and --color-accent-subtle for the fill.

Accessibility

Role and pattern

Native <input type="checkbox"> (WAI-ARIA APG Checkbox). Groups use <fieldset> and <legend>. A tri-state parent exposes aria-checked="mixed" automatically through indeterminate.

Keyboard

KeyAction
Tab / Shift+TabMoves between checkboxes; each is a tab stop.
SpaceToggles the focused checkbox.
EnterSubmits the form if it has a submit button; it does not toggle.

Focus

The shared ring (2px --color-focus-ring, 2px offset) is drawn on the box on :focus-visible. It is never removed in favour of a custom check graphic.

Labelling

Wrap the input in a <label> or use for and id. The label states the affirmative: "Email me the gallery link". Group legends name the question, not the control type. Required checkboxes set required and say "required" in the label.

Motion

The tick appears without animation, so there is no motion to reduce.

Touch

The whole row is the target: at least 44px tall and as wide as its column. The 20px box alone would meet the 24px minimum only because the label extends it.

Content

  • Phrase the label as the option being chosen, in the affirmative: "Email me the gallery link", not "Don’t email me".
  • Group legends ask a question or name a set: "Deliverables", "Which photos should be printed?".
  • Do not use a checkbox for an action that applies immediately; that is a switch.
  • Sentence case, no trailing punctuation.
