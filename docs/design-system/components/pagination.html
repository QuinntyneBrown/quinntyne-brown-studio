Pagination

Pagination splits a long list into pages and lets people step through them or jump to one.

WCAG 2.2 AAStatus: stableLandmark <nav>

Overview

Use pagination for lists that have a stable order and a known length: sessions in the admin app, blog posts, print requests. People can bookmark a page, return to it, and know how far they are. For a short list, show everything. For a gallery of photos use a "Load more" button so the grid does not jump.

  • Numbered: previous, a window of page numbers with ellipses, next. The default for tables on wide screens.
  • Simple: only previous and next with a "Page 2 of 8" status. Use it on phones and when the total is unknown.
  • With page size: add a select for "Rows per page" next to the numbered pagination in dense tables.

Pagination changes the list shown by a table; announce the change, and keep sort and filters when moving between pages.

Anatomy

  1. Previous / nextIcon-only links with aria-label. Disabled at the ends with aria-disabled="true".
  2. Page numberA link per page; the current one is filled ink with aria-current="page".
  3. EllipsisNon-interactive span standing for skipped pages.

Variants

All variants are one <nav class="pagination">; they differ in what is inside.

Sizes

Pagination has one size: 44px square targets (<code>--control-height-md</code>) at 14px text.

  • Disabled previous on page 1 and next on the last page keep their place so the row does not shift; they use aria-disabled="true" and tabindex="-1" because they are links.
  • Current uses an ink fill with the inverse text, plus aria-current; the page number is also in the table caption or heading.
  • Loading: set aria-busy="true" on the list being paged, not on the pagination.

Responsive behaviour

  • Numbered pagination shows at most seven items on desktop (first, last, current and two neighbours each side with ellipses).
  • Below 480px (--layout-breakpoint-sm) switch to the simple variant: previous, "Page 2 of 8", next.
  • The row wraps and centres if it does not fit; items keep 44px height.
  • The page-size select stays above the pagination on phones.

Theming

Pagination reads --color-fg-default on --color-bg-canvas; the current page inverts through --color-accent and --color-fg-on-accent, which swap in the dark theme. Disabled items use --color-fg-disabled, which is intentionally low-contrast.

Accessibility

Role and pattern

A <nav aria-label="Pagination"> of links. There is no dedicated APG pattern; this follows the Navigation landmark pattern. Page numbers are real links with href so the browser can open them in a new tab and the URL carries the page.

Keyboard

KeyAction
Tab / Shift+TabMoves through previous, page numbers and next. Disabled items are skipped.
EnterFollows the focused link.
SpaceNot used: links activate with Enter only.

Focus

Links take the shared ring (2px --color-focus-ring, 2px offset). After a page change, move focus to the list's heading or caption and announce the result ("Showing 11 to 20 of 76 sessions") in a polite live region, so keyboard users do not land back at the top of the page.

Labelling

The nav is labelled "Pagination". Numbers are named "Page 3" through aria-label so the digit is not read alone; the current link keeps its label plus aria-current="page". Icon-only previous and next links are named explicitly.

Motion

No motion.

Touch

Every item is at least 44px square (--control-height-md) with 4px gaps, meeting the comfortable target.

Content

  • Do not label with "Page" visibly; digits and arrows are enough. The accessible names add "Page".
  • Show the range in text near the list: "Showing 11 to 20 of 76 sessions".
  • Simple variant text is "Page 2 of 8", sentence case.
  • Keep the same page size and order when returning to a list.
  • Never paginate fewer than two pages' worth: hide the control when there is one page.
