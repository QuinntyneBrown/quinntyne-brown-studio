Schedule calendar

The schedule calendar shows a week of sessions at a glance: seven day columns, each with its date and its appointments.

WCAG 2.2 AAStatus: stableStatic week grid

Overview

Use the schedule calendar to see what is booked this week and open a session. It is a read-only overview, not a date picker. To move between weeks use the date navigator; to pick a date in a form use the text field with a native date input.

  • Seven columns, Monday to Sunday, each with a weekday, a date numeral and zero or more appointments.
  • An appointment shows time, session name (a link) and location.
  • Empty days say "No sessions" so nobody wonders whether data is missing.

Anatomy

  1. Weekdayh3 in caption type and muted ink; the full day name.
  2. DateSerif numeral in strong with a <time>.
  3. AppointmentLeft-ruled block with time, linked session name and location.

  • Today should be marked with aria-current="date" on its day and a visible "Today" label next to the date; the visual accent needs a CSS rule not yet in the sheet (see the report).
  • Busy day: appointments stack in time order; the column grows. Do not clip.
  • Error: replace the grid with an alert and Retry; keep the date navigator above so people can try another week.

Responsive behaviour

  • The seven columns keep a 7rem minimum; the grid scrolls sideways inside .calendar-wrap. The page never scrolls sideways.
  • The wrap is focusable and labelled, so keyboard users can pan with the arrow keys.
  • At 390px two to three days show at once. For a phone-first flow render the same days as a vertical agenda list instead: a <ul> of days with their appointments.
  • Appointments never truncate; locations wrap.

Theming

Border from --color-border-default, appointment fill --color-brand-subtle and ruled edge --color-brand, weekday in --color-fg-muted. All swap with the theme; the appointment text keeps 4.5:1 against its fill.

Accessibility

Role and pattern

A static group of day regions: a labelled scroll region containing seven divs, each headed by an h3. It is not the APG date picker grid: cells are not navigated with arrows, so no grid role is used. Appointments are links.

Keyboard

KeyAction
Tab / Shift+TabMoves to the scroll region, then to each appointment link in day order.
← →Pans the focused scroll region.
EnterOpens the session.
EscNo effect.

Focus

The scroll region shows the shared ring; so does each link. After changing week with the date navigator, focus stays on the navigator and the region's label is updated.

Labelling

The region is named "Week of 12 October 2026". Each day heading is the full day name; the <time> gives the machine date. A link's text is the session name; the time precedes it in the same block. Announce week changes in a live region.

Contrast

Motion

No motion. Switching weeks does not animate.

Touch

Appointment links are small text; give them at least 24px height by keeping appointment padding and 8px between appointments. A tap on the whole block should open the session where possible.

Content

  • Weekday names are written in full; the date numeral has no month (the navigator names it).
  • Times use 24-hour format: "14:00".
  • Appointment names are the session names, locations are venue names; no addresses.
  • Empty days say "No sessions". Do not leave them blank.
  • Do not show cancelled sessions without the word "Cancelled".
