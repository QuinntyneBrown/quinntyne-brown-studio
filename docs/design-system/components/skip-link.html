Skip link

A skip link is the first thing a keyboard user can reach on every page. It jumps past the repeated header and navigation straight to the main content.

WCAG 2.2 AAStatus: stableWCAG 2.4.1 Bypass blocks

Overview

Every page has one, as the very first focusable element, pointing at #main. It is invisible until it receives keyboard focus, then it appears at the top left, above everything else, so sighted keyboard users can see and use it.

  • Skip to content (href="#main") is the standard link, used on every page of the marketing, client and admin sites.
  • Additional skip links (for example "Skip to filters" on a long results page) follow it only when a page has a second large block that is expensive to tab through.

It is a plain link to an in-page target, not a button. This documentation page has one: press Tab once from the top of this page to see it.

Anatomy

  1. LinkA real <a href="#main"> with the text "Skip to content"; it is the accessible name.
  2. Visible-on-focus boxRaised surface with 12px padding and square corners, positioned above all other layers (--z-skip).

The skip link has one look. The examples below force the focused state because the resting state is, by design, off screen.

Sizes

The skip link has one size: 14px text in a box with 12px padding.

States

A skip link has two states: off screen at rest, and visible on focus. The matrix forces the focused state because the resting one cannot be seen.

Both themes

Skip to content
Skip to content
  • Resting: positioned above the viewport (top: -80px), still in the tab order and in the accessibility tree.
  • Focused: top: 12px, drawn above the header at --z-skip, with the shared focus ring.
  • Activated: the browser moves the viewport to #main; give the target tabindex="-1" so focus follows, not only scroll.

Responsive behaviour

  • It works the same at every width. It is shown on keyboard focus only, so touch users never see it.
  • It is position: fixed, so a sticky header does not cover it.
  • In zoomed layouts (200-400%) it stays at the top left and the text does not truncate.
  • In the admin workspace it must come before the sidebar so one press skips both.

Theming

The skip link uses --color-bg-surface-raised with --color-fg-default and the shared focus ring, so it reads as a raised label in both themes. No component tokens.

Accessibility

Role and pattern

WCAG 2.4.1 Bypass Blocks. Technique G1: a link at the top of the page to the main content. It is a standard <a href>; no ARIA is needed. The target is the <main id="main"> landmark.

Keyboard

KeyAction
TabFrom the page top, the first press focuses the skip link and shows it.
EnterMoves focus and scroll to the main content.
Tab againMoves on to the first element of the header if you ignore the link; the link hides again.

Focus

Focus starts on this link. After activation, focus lands on the target (tabindex="-1" on main) so the next Tab goes to the first control inside the content. The focus ring is the shared 2px --color-focus-ring.

Labelling

The text "Skip to content" is the name. Do not use aria-label; the visible text and the name must match. Do not hide it with display: none or visibility: hidden, which would remove it from the tab order.

Contrast

Text on raised surface
Focus ring on surface

Motion

It appears instantly; there is no slide-in, so nothing changes under reduced motion.

Touch

When shown, the box is about 44px tall (12px padding around 14px text) and is only reachable by keyboard or switch access.

Content

  • Use "Skip to content" for the main link, in sentence case.
  • A second link names its destination: "Skip to states", "Skip to filters".
  • Do not translate it into a slogan or a call to action.
  • Keep it one line; it must not wrap at 320px.
